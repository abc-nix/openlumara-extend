{# chat-pro - the branch map of the open chat. Only fork points and their alternatives are listed: linear runs of messages collapse to nothing, so a long chat stays a handful of rows and indentation counts *branch levels*, not messages (a 113-message chat with two splits is four rows, not 113). a branch row: click switches the chat to that branch; the faint x on off-path branches opens the inline Delete/Cancel bar. a fork row is a label, not an action - it says where the split happens and how many alternatives there are. this file is rendered twice (sidebar tab and the right dock) from the same markup, so both stay identical. #}
